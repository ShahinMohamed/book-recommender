# Demo catalog

The Docker quick start includes a deterministic 600-book subset of the
[Books Dataset](https://www.kaggle.com/datasets/elvinrustam/books-dataset),
released as CC0. It exists so a new checkout starts without Kaggle credentials
or a long embedding job.

`demo_books.csv`, `demo_embeddings.npy`, and their metadata are generated by
`python -m scripts.generate_demo_data`. Use `make ingest-full` to replace the
quick-start catalog with all 97,805 cleaned unique titles.
